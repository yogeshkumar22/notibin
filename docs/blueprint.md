# **App Name**: NotiBin

## Core Features:

- Notification Interception: Intercept and store notifications as they appear.
- Notification List: Display a list of all stored notifications, sorted by time of arrival.
- Detailed View: Allow the user to select a single notification to view its full content.
- Notification Management: Enable users to clear all notifications or delete them individually.
- Notification Summarization: A summarization tool, using AI to create summaries of long or complex notifications.
- Categorization: Offer optional categorization of notifications based on app source, set by the user.

## Style Guidelines:

- Background color: Dark, desaturated blue (#223343) to reduce eye strain during extended use.
- Primary color: A brighter, but still subdued, blue (#64B5F6) for headings and key UI elements.
- Accent color: Analogous cyan (#4DD0E1) for interactive elements, such as buttons and toggles, providing a clear visual cue for user interaction.
- Use a clear, readable sans-serif font to ensure legibility, especially in detailed notification views.
- Simple, outlined icons to represent app sources and actions, maintaining a clean interface.
- Use subtle, non-distracting animations when notifications are received or cleared to provide gentle feedback to the user.
